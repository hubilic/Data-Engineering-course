# PostgreSQL

SQL coursework for weeks 6–9, including queries and saved result screenshots.

| Week | Focus | In-class exercises | Homework |
| --- | --- | --- | --- |
| 6 | Filtering, sorting, dates, strings, and subqueries | [IC6](week6/IC6/) | [HW6](week6/HW6/) |
| 7 | Table design, constraints, inserts, updates, and triggers | [IC7](week7/IC7/) | [HW7](week7/HW7/) |
| 8 | Joins, relationships, and queries across multiple tables | [IC8](week8/IC8/) | [HW8](week8/HW8/) |
| 9 | Grouping, conditional aggregation, subtotals, and window calculations | [IC9](week9/IC9/) | [HW9](week9/HW9/) |

Each exercise folder contains a `.sql` script. Most also contain `.png` screenshots of the results.

Open scripts in a PostgreSQL client and run them against a practice database containing the required tables and data. The exercises are individual queries and examples; this module does not include a complete database setup. Some scripts create or change tables and data.

Source: [PostgreSQL_DE](https://github.com/hubilic/PostgreSQL_DE). The original SQL files, screenshots, and folder structure are preserved.
