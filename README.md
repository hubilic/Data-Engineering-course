# Data Engineering Course

Course exercises organized by module and week.

| Module | Weeks | Contents |
| --- | --- | --- |
| [Python Fundamental](python-fundamental/) | 1–5 | Python basics, collections, functions, object-oriented programming, and exception handling |
| [PostgreSQL](postgresql/) | 6–9 | SQL queries, table design, joins, and aggregations, with result screenshots |

## Repository structure

```text
Data-Engineering-course/
├── python-fundamental/
│   └── Python_Week 01-05/
│       ├── IC_1/
│       ├── IC_2/
│       ├── IC_3/
│       ├── IC_4/
│       └── IC_5/
└── postgresql/
    ├── week6/
    ├── week7/
    ├── week8/
    └── week9/
```

Each module has a README with links to its weeks. `HW` folders contain homework; `IC` folders contain in-class exercises and meeting examples. The original exercise filenames and folder structures are preserved inside each module.

## Using the exercises

- Open the [Python module](python-fundamental/) and choose a week. Run individual `.py` exercises with Python 3; some scripts prompt for input.
- Open the [PostgreSQL module](postgresql/) and choose a week. Run `.sql` files against a PostgreSQL practice database with the tables and data required by the exercise. Accompanying `.png` files show saved results.
