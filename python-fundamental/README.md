# Python Fundamental

Python coursework for weeks 1–5.

| Week | Focus | Exercises |
| --- | --- | --- |
| 1 | Variables, types, operators, input, and basic control flow | [IC_1](Python_Week%2001-05/IC_1/) |
| 2 | Collections, ordering, and data-processing exercises | [IC_2](Python_Week%2001-05/IC_2/) |
| 3 | Functions, decorators, and generators | [IC_3](Python_Week%2001-05/IC_3/) |
| 4 | Classes, inheritance, properties, and design patterns | [IC_4](Python_Week%2001-05/IC_4/) |
| 5 | Exceptions and context managers | [IC_5](Python_Week%2001-05/IC_5/) |

Within each week, `HW` folders contain homework, `IC_Exercise` folders contain in-class exercises, and `IC_Meet` folders contain meeting examples. Names vary slightly between weeks and follow the original project.

Run an individual exercise with Python 3, for example from this folder:

```bash
python3 "Python_Week 01-05/IC_1/HW_Exercise/FizzBuzz.py"
```

Some scripts require interactive input, and some exercise files are unfinished placeholders.

Source: [Python_Foundations_DE](https://github.com/hubilic/Python_Foundations_DE). The imported module is named **Python Fundamental**; its original files are preserved.
